# Bank Churn Analysis — Data Prepparation & Exploratory Data Analysis (EDA)

## Business Context
I'm acting as a Data Analyst for a retail bank that has seen an uptick in customer churn alongside slowing growth. This project prepares and explores the bank's customer data to understand the drivers behind churn, as a foundation for future churn-prediction and customer-segmentation work.

## Project Status
This is an initial EDA and data-cleaning project, adapted from Maven Analytics' "Bank Customer Data Prep" guided project. The original brief covers four objectives; I've extended it past the base requirements to include my own exploratory questions and a set of written findings, so it stands as a complete, self-contained analysis rather than a prep-only exercise.

*Note: this is an early portfolio project. It will likely be superseded by larger, end-to-end projects as my portfolio develops further.*

## Objectives
1. Import & QA the data — join two source tables, remove duplicate rows/columns
2. Clean the data — handle missing values and inconsistent formatting
3. Explore feature relationships with churn
4. Prepare the data for modeling
